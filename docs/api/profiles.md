# 公开主页与关注状态

## 接口

- `GET /api/v1/users/:id/profile`：公开昵称、加入时间、粉丝总数、关注总数、当前调用者是否关注及是否本人。
- `GET /api/v1/users/:id/follow`：同一真实资料响应，用于查询关注状态。
- `POST /api/v1/users/:id/follow`、`DELETE /api/v1/users/:id/follow`：复用既有幂等写接口，仍要求有效登录与当前启用账号，禁止自关注。
- `GET /api/v1/users/:id/products?page_size=12&cursor=...`：目标卖家的在售商品，沿用 Product `(created_at,id)` 游标，不展示草稿、下架、预占或售出商品。

资料与在售商品支持匿名读取。提供 Token 时必须验签，不能用无效 Token 静默降级；关系状态只取可信 Context 身份。匿名时 is_following 为 false。Proto JSON 省略默认 false/0，客户端须按零值处理，BIGINT 为字符串。

粉丝/关注计数与关系存在性由 User 单条 SQL 查询同一语句快照取得；不以当前页长度作为总数。公开资料显式映射字段，不返回用户名、密码哈希或权限角色。停用或不存在的目标返回 NotFound。卖家商品由 Gateway 先查询 User，再调用 Product RPC，以卖家条件缩小公开商品范围，不跨库查询。跨服务查询不是分布式事务快照。

## 前端

账号下拉菜单显示真实粉丝/关注数量及个人主页入口，打开菜单时重新读取统计。个人主页提供在售商品、粉丝和关注列表分页；关系列表仍沿用登录后读取的既有策略。卖家主页只公开在售商品，自己的所有状态商品仍在“我的商品”管理。

商品详情采用左图右信息、手机端上下排列，沿用当前系统蓝白配色、价格色与原生 Modal。支持缩略图切换，点击主图在新标签查看大图。卖家卡片展示真实昵称、粉丝数、主页入口及关注状态，自己的商品不展示自关注按钮；未登录点击关注进入登录流程。成功关注/取消后重新读取真实计数并使关注流重载，不做伪造计数。

当前头像为真实昵称首字的默认圆形头像，未实现用户头像上传或自定义头像展示。没有加入尚未实现的“联系卖家”按钮。
